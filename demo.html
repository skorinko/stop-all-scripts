How to try it

  1. Turn on Stop All Scripts in Safari (how). Every box above turns green: JavaScript runs. The javascript: link's box turns green when you click it.
  2. Open the extension’s menu: on a Mac, click its toolbar button; on iPhone and iPad, tap the page menu button beside the address, then Stop All Scripts.
  3. Turn the switch on. The page reloads, and every box stays red: no script ran.
  4. Choose 10 minutes to let JavaScript run again for a while, or Stop Now to end that.

This page is part of Stop All Scripts for Safari. It runs no script but its own, loads nothing from other websites, and keeps nothing about you.

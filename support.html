Support

Turning it on, using it, and what to do when a website needs its scripts.

Turn it on: Mac

  1. Open the Stop All Scripts app once. Its window shows whether the extension is on.
  2. Click Quit and Open Safari Settings…, or in Safari choose Safari › Settings › Extensions.
  3. Tick Stop All Scripts. Then, under Websites, choose Stop All Scripts and set Other Websites to Allow. It needs that to stop scripts before they start; it does nothing on a website until you turn JavaScript off there.

Turn it on: iPhone and iPad

  1. Open Settings, then Apps, then Safari, then Extensions.
  2. Tap Stop All Scripts and turn on Allow Extension.
  3. Set All Websites to Allow.

Then open the demo page and try it.

Use it

  • Stop JavaScript on a website: click the Stop All Scripts toolbar button and turn the switch on, or press ⌃⇧J. On iPhone and iPad, tap the page menu button beside the address, then Stop All Scripts. The page reloads without its scripts.
  • The whole website, or one address: under the switch, choose the website with its subdomains, or only the address you’re on.
  • JavaScript for a while: in the same menu, choose 10 minutes, 1 hour or Today. It stops again by itself; Stop Now ends it early.
  • Embedded frames: turn on Block embedded frames to keep videos, maps, ads and widgets from loading on that website.
  • All websites: All Websites… in the menu opens the list, the two modes, the defaults and backup. On iPhone and iPad it is also under Settings › Apps › Safari › Extensions › Stop All Scripts › Settings.

Common questions

A website doesn’t work any more

Many websites need JavaScript for some things, and some for everything. Let it run for 10 minutes, or turn the switch off for that website.

Some scripts ran anyway

A page that was open before you turned the switch on, or that Safari brings back from its cache when you go back, may still have its scripts. Reload it; the menu offers Reload when it sees this.

A video or map inside the page still works

It comes from another website, in a frame, and runs that website’s scripts. Turn on Block embedded frames for the page’s website to keep frames from loading.

The toolbar button

It shows { ■ } where JavaScript is stopped and { } where it runs, with the number of scripts stopped. To hide it, choose View › Customize Toolbar in Safari.

Moving my list to another device

On the websites page, choose Export…, then Import… on the other device. Websites already on both are kept as last changed.

Downloads from the extension

The first time you export, Safari may ask whether to allow downloads from a long code of letters and numbers: that’s the extension’s own address in Safari.
